1. THE BLANK BOOKING PAGE - MY BUG, FOUND AND FIXED
---------------------------------------------------
You were right, and it was my fault. Narrowing the calendar to 1080px last round
is what made it disappear. I reproduced it on your live site and traced it.

What was happening: while GoHighLevel's script starts up, it parks the calendar
iframe off-screen at `position:absolute; left:-9999px` so it can measure it
without any flicker. In CSS, an absolutely positioned box is measured against
its nearest POSITIONED ancestor - and my container wasn't positioned. So the
iframe escaped the 1080px box and got measured against the full 1905px window
instead. The measurement came back for the wrong width, GoHighLevel never
finished initialising, and it left the iframe hidden. Result: a blank page.

The fix is one word - `position:relative` on the container. That keeps the
measuring step inside the 1080px box, so the calendar initialises correctly and
appears.

Confirmed on three separate fresh loads of your live site: calendar renders at
1080px with both columns intact.

This is why it was so confusing: at full width it worked, and it also worked
when I narrowed it AFTER the page had loaded during testing. It only broke when
the narrow width was there from the start - which is exactly the real-world case
I should have retested and didn't. Apologies for the round trip.

I've left a comment in the CSS marking that line as load-bearing, so nobody
(including me) removes it later.
